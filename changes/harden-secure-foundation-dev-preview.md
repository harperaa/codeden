- **A Secure Foundation project's dev preview is set up with one confirmation.** Once the setup has finished, the project's Secure Foundation setup card shows **Set up the dev preview**. It opens Settings › Dev preview with the fields filled in for such a project: `npm ci` as the prepare command, `PORT`, the link from the output, and as the dev command `doppler run --project <project> --config dev -- npm run dev` with Doppler (Doppler remembers its project per folder, and a preview runs in another folder) or `npm run dev` with `.env.local`. The values only fill the form: the usual **Start preview…** and **Save and allow** still store them, and nothing runs before that. With `.env.local` the form says what is left for you (copying that file into the preview's folder), and the card and the form say that the Convex dev process runs separately, with its command. Projects made before this get the `.env.local` values and a note. See [Dev preview](docs/dev-preview.md#secure-foundation-projects).
- **Troubleshooting for previews that can't ask.** A preview's commands have no terminal and no input, so a tool's question (`next dev`'s upgrade menu, for one) is skipped or ends the command instead of waiting. [Dev preview › Troubleshooting](docs/dev-preview.md#troubleshooting) now says what that looks like in the log, and covers `next: command not found` and `Doppler Error: You must specify a project`.

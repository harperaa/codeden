- **Secure Foundation shows what it needs before it starts.** Opening Secure Foundation first checks this computer for the tools and sign-ins every setup needs. When something is missing, a requirements page comes up in front of the form, in the format of the first-run setup: Node.js, npm, git, the Doppler CLI and the GitHub CLI with their versions and an install command to copy, and Convex, Doppler, GitHub and Vercel with their sign-in state, a **Sign in** button and a **Create an account** button to the service's own page. Clerk is listed as an account you need afterwards, to claim your app, and is checked with Clerk's own command-line tool: **Create or Sign-in** starts its sign-in in your browser, and **I have an account** marks the row done in this browser when the tool can't tell. It never holds the setup back. **Check again** reruns the checks, the page leaves by itself once everything is there, and **Continue anyway** is always offered. **Settings › Secure Foundation Setup** shows the same page at any time. No token or password is asked for, shown or kept. See [Secure Foundation](docs/secure-foundation.md#requirements).

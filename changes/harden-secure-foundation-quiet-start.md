- **A new Secure Foundation project starts with automatic work off.** The project is created in Manual mode, and nothing but the setup session you pressed Go for starts in it: pull requests, issues and reviews on GitHub don't wake its project manager, and scheduled or event automations and issue triage don't run. What arrives is kept for the project manager's next turn. The form, the verification view and the project's Secure Foundation setup card say so. To turn automatic work on, press **Turn on automatic work…** in that card (or the mode button beside the project's name) and choose **Assisted**; setting the mode back to Manual turns it off again. Projects made before this keep the mode they have, and other projects are unchanged. See [Secure Foundation](docs/secure-foundation.md#automatic-work-starts-off).
